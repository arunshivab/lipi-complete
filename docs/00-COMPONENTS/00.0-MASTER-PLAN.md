# 00.0 — Master Plan: Component Library + Multi-Theme System

> **Decision Reference**: BASE v1.0 #12 — Custom Razor components + 2 themes  
> **Total Effort**: 12-15 sessions, ~34-41 hours  
> **Timeline**: 4-6 weeks at 1-2 sessions/week  
> **Status**: Phase 0 complete (decision locked); Phase 1 next

---

## OVERVIEW

This plan delivers:
- **41 custom Razor components** (`Lipi*` prefix)
- **Multi-theme architecture** (brand × mode dimensions)
- **2 themes** for v1.0: `lipi-default-light` + `lipi-default-dark`
- **Living style guide page** (`/admin/style-guide`)
- **All built modules refactored** to use Lipi components

## RISK MITIGATION

### Risk 1: Architecture Flaws Discovered Late
**Mitigation**: Phase 4 builds only 15 P0 components first. If theme switching breaks at component #15, we fix architecture before building components 16-41.

### Risk 2: Scope Creep
**Mitigation**: 41 components is the cap. Anything new = v1.1 (CHANGE-LOG.md).

### Risk 3: Existing Pages Break
**Mitigation**: Phase 8 refactors one page at a time with browser test between each. Original pages remain working until refactor verified.

### Risk 4: Dark Mode Color Issues
**Mitigation**: WCAG AA contrast check on every component during Phase 4-6. Style guide page shows side-by-side.

### Risk 5: Performance Regression
**Mitigation**: 41 components = bigger DOM. Test with 100-row table on slow devices. Use `@key` directives. Profile with Chrome DevTools.
