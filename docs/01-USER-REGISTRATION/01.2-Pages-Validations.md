## VALIDATION TIMING

```
On first focus → No validation
On first blur → Validate field, show error if any
On subsequent input → Re-validate (silent if no error, show if error)
On Save click → Validate ALL fields, scroll to first error if any
```

### Validation Pattern
```csharp
// In @code:
private bool _firstNameTouched = false;
private string? _firstNameError;

private void OnFirstNameBlur()
{
    _firstNameTouched = true;
    ValidateFirstName();
}

private void OnFirstNameInput(ChangeEventArgs e)
{
    _firstName = e.Value?.ToString() ?? string.Empty;
    if (_firstNameTouched) ValidateFirstName();
}

private void ValidateFirstName()
{
    if (string.IsNullOrWhiteSpace(_firstName))
        _firstNameError = "First name is required";
    else if (_firstName.Length < 2)
        _firstNameError = "Must be at least 2 characters";
    else if (!Regex.IsMatch(_firstName, @"^[A-Za-z\s]+$"))
        _firstNameError = "Letters and spaces only";
    else
        _firstNameError = null;
}
```

## SAVE BEHAVIOR

```
User clicks "Save User":
  1. Validate all fields → if errors, scroll to first, focus, abort
  2. Generate password (random 12-char, mixed)
  3. Hash password with Argon2id
  4. Begin transaction
  5. INSERT into master.platform_users
  6. INSERT into clinic-specific identity.users (if applicable)
  7. INSERT into master.clinic_memberships (if site admin)
  8. INSERT user roles per Section 5
  9. INSERT audit_event (action: USER_CREATED)
  10. Commit transaction
  11. Send email with credentials (must_change_password = true)
  12. Show success: "✓ User created. Email sent with credentials."
  13. Disable form (fieldset disabled)
  14. Save button → "✓ Saved" (disabled)
  15. Cancel button → "Close" (navigates to /admin/users)
```

## STATUS WORKFLOW

```
active ─────► suspend ─────► reactivate ─────► active
   │                                              │
   │                                              ▼
   ├──────────────────────────────────────► terminate
   │                                              │
   │                                              │
   └──────────────────────────────────────────────┘
                    (no return from terminate)

Special: any active/suspended → terminate (irreversible)
Special: terminate → reactivate (only by SysAdmin+, with reason)
```

### Status Change Confirmation Required For:

## AUDIT EVENTS TRIGGERED

| Action | Event Code | What's Captured |
|--------|-----------|----------------|
| Create user | `USER_CREATED` | All field values |
| Edit user | `USER_UPDATED` | before_state, after_state |
| Suspend | `USER_SUSPENDED` | reason |
| Reactivate | `USER_REACTIVATED` | reason |
| Lock (auto) | `USER_LOCKED_AUTO` | failed_login_count |
| Lock (manual) | `USER_LOCKED_MANUAL` | reason |
| Terminate | `USER_TERMINATED` | reason |
| Reset password | `USER_PASSWORD_RESET` | reset_by user_id |
| Add role | `USER_ROLE_ADDED` | role, scope, added_by |
| Remove role | `USER_ROLE_REMOVED` | role, scope, removed_by |

All events use `IAuditService.LogAsync()` with `AuditActions` constants.
