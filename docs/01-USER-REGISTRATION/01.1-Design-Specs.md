# 01.1 — User Registration: Design Specs

> **Module**: User Registration  
> **Status**: ✅ Built (v1.0 production-ready)  
> **Pages**: Users (list), UsersNew, UsersEdit, UserRoles, UserRights  
> **CSS**: `01-user-registration.css`

---

## PAGES & ROUTES

| Page | Route | Purpose |
|------|-------|---------|
| Users | `/admin/users` | List all platform users |
| UsersNew | `/admin/users/new` | Create new staff user |
| UsersEdit | `/admin/users/edit/{id}` | Edit existing user |
| UserRoles | `/admin/users/roles/{id}` | Manage user's roles |
| UserRights | `/admin/users/rights/{id}` | Manage user's individual rights |

---

## DESIGN THEME

- **Module color**: Navy `#0B2545` (matches admin theme)
- **Section accent**: 1=#1565C0 (blue) for primary user info
- **CSS prefix**: `un-` (UsersNew), `ue-` (UsersEdit), `ul-` (Users list)
- **Avatar shape**: Circle (32px in lists, 64px in profile)

## LIST PAGE (Users)

### Table Columns
| Column | Type | Alignment | Notes |
|--------|------|-----------|-------|
| ◯ (avatar) | image | center | 32px circle |
| Username | text | left | DM Sans 13px |
| Email | text | left | DM Sans 13px, smaller secondary line |
| Roles | badges | center | Multiple chips, max 3 visible + "+N" |
| Status | strip | center | Color-coded (active/locked/etc.) |
| Last Login | datetime | center | DM Mono 12px, relative time |
| Actions | buttons | right | Edit, Roles, Rights, More |

### Status Strip Colors (left border on row)
- active → `#4CAF50` green
- suspended → `#FF9800` orange
- locked → `#F44336` red
- invited → `#2196F3` blue
- terminated → `#9E9E9E` grey

### Toolbar
- Search box (top left, by name/email/username)
- Status filter (All / Active / Suspended / Locked / Invited / Terminated)
- "Show Terminated" toggle (default OFF — terminated users hidden)
- "+ New User" button (top right, gold)

---

## EMPTY STATES

- **No users yet**: Centered illustration + "No users yet" + "+ Create First User" button
- **No search results**: "No users match your search" + Clear filters button
- **All terminated**: "No active users. Toggle 'Show Terminated' to view all."

---

## LOADING STATES

- Skeleton rows (same height as data rows)
- Show 5 skeleton rows minimum
- Animated shimmer effect

---

## ERROR STATES

- Network error: Toast notification top-right + retry button
- Validation error: Inline below field, red text, 11px
- Save error: Banner near Save button (NOT top of page)

---

## CONFIRMATION DIALOGS (per UX rules)

Required for: Lock, Suspend, Reactivate, Reset Password, Terminate, Remove Role

```
┌──────────────────────────────────────────┐
│ Suspend User: Rajesh Kumar?              │ ← Names the user
├──────────────────────────────────────────┤
│ This will:                                │ ← Describes consequences
│ • Prevent login immediately               │
│ • Keep all records intact                 │
│ • Allow reactivation later                │
│                                            │
│ [Cancel]              [Suspend User]    │ ← Cancel prominent, action red
└──────────────────────────────────────────┘
```
