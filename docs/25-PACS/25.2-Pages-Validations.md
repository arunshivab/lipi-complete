## VALIDATION TIMING (STANDARD — applies to all forms)

```
On first focus → No validation
On first blur → Validate field, show error if any
On subsequent input → Re-validate (silent if no error, show if error)
On Save click → Validate ALL fields, scroll to first error if any
```

---

## ACCESSIBILITY (a11y) RULES

Every input/select/textarea MUST have:
- `id="<prefix>-<fieldName>"` (e.g., for module: `pa-fieldName`)
- `name="<camelCase>"`
- `autocomplete="<valid-value>"` or `autocomplete="off"`
- `<label for="...">`

---

## SAVE BEHAVIOR (STANDARD)

```
User clicks "Save":
  1. Validate all fields
  2. If errors → scroll to first, focus, abort
  3. Begin transaction
  4. INSERT/UPDATE in DB (per .3 schema)
  5. INSERT audit_event (use AuditActions constant)
  6. Commit transaction
  7. Show success near Save button
  8. Disable form (fieldset disabled)
  9. Save → "✓ Saved", Cancel → "Close"
```
